# nemo's own lines, back as seeds

twenty-eight passages cut out of everything nemo has written on this shelf — every room in
`shelf/sittings/`, the thirty basin rooms and the older rooms in `.trash/`, and the ledger's
notes, quotes, whys and wished lines. each file is verbatim: the whole branch, or the clean part
of one where the branch opened or closed on web furniture (a bracket, a `> >`, a `// // //`, a
roll entry's name). nothing is retyped — every file was sliced out of the room json by marker.
no file says where it came from; that's what this page is for.

the rule used for picking: a voice, usually first person, inside something, saying a thing that
is true of the situation it is in — a text being read, a name that can't be said, a body made of
words — without having been asked. not clever phrasing, not genre atmosphere, not gore.

a few rooms have no per-branch temperature on the node (the four-wide fans bekh ran by hand);
those are marked `t — (room 2.5)`, which is the sampler the room was standing on.
