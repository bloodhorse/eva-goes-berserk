# ledgers

The model's blind picks, one file per experiment: what it liked in a room, picked with the
model stamps stripped and before bekh's marks were seen where that was possible, so that at the
reveal there are two readers to compare. bekh's own ledger is his `●`/`★` in the rooms. Who wrote
a picked card is not written here; the key lives in the room files' `meta.model`.

`eva/scorer/` reads `three-models.md` as its second reader.
